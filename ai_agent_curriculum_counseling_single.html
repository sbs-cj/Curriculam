BEFORE YOU START

수강 전 알아두시면 좋은 점

Q.

어떤 AI 에이전트를 배우나요?

Claude Code를 중심으로 파일과 코드를 다루고, 외부 도구를 연결하며, 실행 결과를 검증하는 업무용 에이전트 활용을 배웁니다. 대화만 하는 챗봇 제작이나 특정 노코드 도구만 익히는 과정과는 구성이 다릅니다.

Q.

코딩이 처음이어도 가능한가요?

초반에는 환경 구축과 첫 세션부터 시작하지만, 터미널·파일·간단한 코드와 데이터 구조를 다룹니다. 기본적인 컴퓨터 사용과 파일 관리가 필요하며, 완전 입문자는 수강 전 사전 학습과 설치 준비를 상담하는 것이 좋습니다. 심화 파트는 앞선 입문 내용을 이해한 상태를 기준으로 합니다.

Q.

8일 동안 예제 80개를 모두 완성하나요?

원본의 80개는 필수 실습·시연·숙제를 합친 예제 구성입니다. 수업은 필수 예제를 중심으로 진행하며, 모든 예제를 수업 시간 안에 완성하거나 80개의 독립 서비스로 배포하는 것을 뜻하지 않습니다. 개인별 진행 속도에 따라 복습과 추가 실습이 필요합니다.

Q.

입문과 심화에서는 무엇이 달라지나요?

입문 4일은 환경·기본기·Git·스킬·훅을 통해 작업을 안정적으로 진행하는 방법을 익힙니다. 심화 4일은 MCP·API·병렬 에이전트·하네스·통합 배포로 범위를 넓힙니다. 단과 수강 가능 여부와 일정은 별도 안내를 확인해 주세요.

Q.

수강 전에 무엇을 준비하나요?

문서 기준 환경은 Windows 11, VS Code, Node.js 24, Python 3.13입니다. Claude Code에 사용할 계정과 GitHub 계정, 프로그램 설치 권한을 확인해 주세요. 필요한 이용권과 버전은 개강 안내를 기준으로 준비하고, 실습에는 개인·회사 민감정보 대신 예시 데이터를 사용합니다.

Q.

API 키가 없거나 비용이 걱정되면 어떻게 하나요?

원본에는 일부 API 실습의 로컬 모의 서버와 샘플 모드, 하네스의 로컬 검증 예제가 포함되어 있습니다. 다만 실제 Claude Code·외부 API의 이용 요금까지 모두 무료라는 의미는 아닙니다. 구독·호출 비용과 수강료 포함 여부를 확인하고 예산 상한을 정해 실습합니다.

Q.

자동 실행은 사람의 확인 없이 진행하나요?

수업에서는 권한 검토, 비밀키 점검, 읽기 전용 에이전트, 완료 조건과 예산 검증을 함께 다룹니다. 실제 업무에 적용할 때는 대상 데이터와 실행 범위를 제한하고, 공개·배포·변경 같은 중요한 작업은 별도로 확인해야 합니다.

Q.

마지막에 무엇을 가져갈 수 있나요?

일차별 점검 도구와 스킬·훅·MCP·에이전트 구성 예제를 바탕으로, 팀에서 재사용할 플러그인 꾸러미와 운영 계획을 정리하는 것이 목표입니다. 원본의 자료 639장과 예제 80개는 교육 자료 규모이며, 개인별 완성 결과물의 수나 수준을 보장하는 수치는 아닙니다.
