BEFORE YOU START

수강 전 알아두시면 좋은 점

코딩을 처음 해도 따라갈 수 있나요?

사무 업무의 예시로 개념을 설명하고 Claude 웹과 Claude Code 앱에서 자연어로 요청하며 배웁니다. 코드를 전부 외울 필요는 없지만 결과를 읽고 숫자·권한·화면을 확인하는 연습에는 직접 참여합니다.

Claude 웹과 Claude Code 앱만 사용하나요?

요청·계획·구현·검토는 두 도구를 중심으로 진행합니다. 작업 보관과 공유를 위한 GitHub 계정·연결 권한, 결과 확인용 브라우저는 필요합니다. API·MCP·훅은 강사 제공 예제와 설정으로 학습하며, 별도 개발 도구 설치를 핵심 학습 목표로 삼지 않습니다.

추가 계정이나 비용이 있나요?
