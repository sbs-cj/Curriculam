과정 개요

원본 과정: AI바이브코딩
수업 목표

Claude Code를 개발 파트너로 사용해 실제 DB가 연동되는 웹 서비스를 만들고 배포하는 바이브코딩 워크플로우를 익힙니다.

수업 설명

환경 구축부터 React 포트폴리오, 커뮤니티, SNS 프로토타입, 실서버 배포까지 이어집니다.

주차별 커리큘럼

4일 과정
Week 01

환경구축 & React 포트폴리오

Claude Code 개발 환경을 세팅하고 MUI 기반 React 포트폴리오를 제작합니다.

  • Node.js, VSCode, Claude Code CLI 설치
  • Vite React와 MUI 통합 설정
  • CLAUDE.md 기반 자동 가이드 시스템 구축
  • 웹 기본 개념, UI 요소, Flexbox 실습
  • 개인 브랜딩 컬러를 반영한 포트폴리오 제작
Week 02

데이터베이스와 커뮤니티

UI에서 필요한 데이터 구조를 역으로 도출하고 Supabase와 연결합니다.

  • Supabase MCP 설치 및 계정 연동
  • DB와 스키마 개념 이해
  • 커뮤니티 UI 기획과 역방향 설계
  • 게시판·댓글·방명록 시스템 구현
  • 실시간 데이터 연동 테스트
Week 03

SNS와 고급 기능

모바일 친화적인 SNS 구조를 설계하고 고급 AI 활용 방식으로 확장합니다.

  • 웹과 앱 디자인 차이 분석
  • 모바일 우선 UI 기획
  • SNS DB 구조 분석
  • 게시글·좋아요·댓글 기능 구현
  • Projects 탭과 DB 최적화
Week 04

포트폴리오 완성과 배포

개인 브랜딩 포트폴리오를 완성하고 실제 운영 가능한 형태로 배포합니다.

  • 포트폴리오 레퍼런스 분석
  • About Me와 Hero 섹션 완성
  • 선택형 인터랙티브 UI 적용
  • Netlify와 Supabase 배포 준비
  • 무료 플랜 제한과 비용 최적화 체크
