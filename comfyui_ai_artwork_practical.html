ComfyUI 기반 AI아트웍 실무

Stable Diffusion과 ComfyUI 워크플로우를 설계하는 4일 과정

4일16시간RunDiffusion · ComfyUI · Stable Diffusion · FLUX

과정 개요

원본 과정: AI아트웍
수업 목표

ComfyUI의 노드 기반 구조를 이해하고 ControlNet, IP-Adapter, Inpaint/Outpaint, 영상 생성까지 활용해 개인 아트웍을 완성합니다.

수업 설명

원본 HTML의 1회차부터 4회차까지의 수업 항목을 유지했습니다. 누락된 로컬 이미지 대신 ComfyUI와 RunDiffusion 예제 화면, 원본 HTML의 RunComfy 이미지를 연결했습니다.

일차별 커리큘럼

4일 과정
Day 01

ComfyUI 입문

ComfyUI 기본 워크플로우와 안정적인 이미지 생성 원리를 이해합니다.

  • RunDiffusion 클라우드 환경 구축
  • ComfyUI 인터페이스와 노드 개념 이해
  • 첫 이미지 생성과 결과 분석
  • Diffusion 모델 생성 원리
  • 체크포인트·임베딩·K-Sampler 매개변수 실습
  • ControlNet 기본 개념
Day 02

ComfyUI 고급 기법

ControlNet과 프롬프트 기법으로 복잡한 창작 의도를 구현합니다.

  • OpenPose ControlNet 포즈 제어
  • Live Portrait 표정 제어
  • Canny와 Depth ControlNet
  • 복합 ControlNet 워크플로우
  • Gligen 위치 지정 생성
  • VAE 출력 최적화
  • GPT 활용 프롬프트 엔지니어링
Day 03

이미지 편집과 영상 생성 마스터

참조 이미지, 얼굴 일관성, 편집, 영상 생성까지 확장합니다.

  • IP-Adapter 스타일 전이
  • FaceID 얼굴 일관성 제어
  • Inpainting과 Outpainting 실전
  • 비디오 생성 모델 활용
  • XY Plot 매개변수 분석
  • 이미지 업스케일링 전략
Day 04

실전 프로젝트와 최적화

개인 아트웍 프로젝트를 완성하고 포트폴리오로 공유합니다.

  • 콘텐츠 제작 워크플로우 구상
  • 버츄얼 아트·일러스트·컨셉 아트 적용
  • 가상 팝업스토어 기획안 제작
  • 조형물·티셔츠·굿즈 이미지 합성
  • 작품 업로드와 피드백
