SUBJECT 01

UX/UI 1

UX/UI 개념 UX/UI 개념 & 사용자 중심 디자인

8개 항목
01 DAY UX/UI 1UX/UI 개념 UX/UI 개념 & 사용자 중심 디자인
UX와 UI의 차이, Design Thinking 과정 이해, Usability·Accessibility 개념 학습
02 DAY UX/UI 1UX 리서치 UX 리서치 & 와이어프레임 기초
사용자 리서치(설문·인터뷰) 기법, Wireframe·Prototype 개념 학습
03 DAY UX/UI 1Figma 컴포넌트 Figma — 컴포넌트 시스템 이해
Figma UI 기본 사용법, 컴포넌트의 필요성과 요소 컴포넌트화 방법
04 DAY UX/UI 1Figma 인터랙션 Figma — 인터랙션 & 프로토타이핑
클릭·드래그 액션 인터랙션 디자인, 프로토타입 제작 및 공유 학습
05 DAY UX/UI 1모바일 UX/UI 모바일 UX/UI 디자인
반응형 디자인 원칙, 모바일 vs 데스크탑 UI 차이, A/B 테스트·사용자 피드백
06 DAY UX/UI 1UI 리디자인 UI 리디자인 실습
최신 UX/UI 트렌드(다크모드·뉴모피즘) 분석, UX 개선 포인트 도출 → UI 리디자인
07 DAY UX/UI 1프로젝트 기획 프로젝트 기획 & 디자인
개인 프로젝트 주제 선정, 와이어프레임·플로우 차트 작성, Figma로 UI 만들기
08 DAY UX/UI 1프로토타입 테스트 프로토타입 & 사용성 테스트
프로토타입 제작 및 인터랙션 추가, 테스트를 통한 UX/UI 개선
SUBJECT 02

UX/UI 2

UX 프로젝트 기획 UX — 프로젝트 기획

8개 항목
01 DAY UX/UI 2UX 프로젝트 기획 UX — 프로젝트 기획
개인 프로젝트 주제 선정, 와이어프레임·플로우 차트 작성, Figma를 활용한 UI 만들기
02 DAY UX/UI 2UX 기획 고도화 UX — 프로젝트 기획 고도화
서비스 IA(Information Architecture) 구성, UX Flow·페르소나·사용자 여정 맵(Journey Map) 제작
03 DAY UX/UI 2UX 기획 고도화 2 UX — 프로젝트 기획 고도화 2
브랜드 UI 스타일 가이드(Color·Typography·Icon System) 구축, 화면 구성요소 정의 및 사용자 중심 정보 배치 전략
04 DAY UX/UI 2프로토타이핑 프로토타이핑 & 사용성 평가
와이어프레임(초안 디자인) 최종 개선, 피드백으로 Visual Hierarchy 활용 와이어프레임 제작·개선
05 DAY UX/UI 2UI 디자인 적용 UI 디자인 적용
와이어프레임(초안) 디자인 적용, 브랜드 콘셉트·리서치 정보·사용자 경험 반영 프로세스 페이지 제작
06 DAY UX/UI 2UI 디자인 적용 2 UI 디자인 적용 2
디자인 시스템 적용하여 앱 디자인 시안 제작, 브랜드 콘셉트·리서치 정보·사용자 경험 반영 프로세스 페이지 제작
07 DAY UX/UI 2UI 디자인 고도화 UI 디자인 고도화
개인 프로젝트 디자인 고도화, 피드백 루프로 사용성 개선
08 DAY UX/UI 2최종 산출물 최종 산출물 마무리
UI 디자인 마무리, 프로세스 페이지 디자인 고도화 및 마무리
