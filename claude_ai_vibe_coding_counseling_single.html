04

BEFORE YOU START

수강 전 알아두시면 좋은 점

Q.

코딩이 처음이어도 수강할 수 있나요?

AI를 활용해 실습하지만 기본적인 파일·폴더 관리와 컴퓨터 사용은 필요합니다. HTML·CSS와 웹 구조에 대한 이해가 있으면 수업을 따라가는 데 도움이 됩니다. 처음 시작하는 분은 현재 수준에 맞는 사전 학습과 실습 준비사항을 상담해 주세요.

Q.

일반적인 웹 개발 수업과 무엇이 다른가요?

Claude Code를 개발 파트너로 활용해 요청을 작성하고, 생성된 화면과 기능을 확인하며 수정하는 흐름에 집중합니다. 코드를 전혀 이해하지 않아도 모든 서비스가 완성되는 방식은 아닙니다. 화면·데이터·배포의 기본 개념과 검토 습관을 함께 익힙니다.

Q.

수업을 마치면 어떤 결과물을 남길 수 있나요?

브랜딩 포트폴리오, 데이터가 연결된 커뮤니티, SNS 프로토타입을 단계별로 실습하고 최종 포트폴리오의 배포까지 진행하는 구성입니다. 결과물의 범위와 완성도는 사전 경험과 개인별 실습 진행 상황에 따라 달라질 수 있습니다.

Q.

과정은 며칠 동안 진행되나요?

총 8일·24시간이며, Week 01~04의 네 단계로 구성했습니다. 각 단계는 2회·6시간 분량으로 묶어 안내합니다. 실제 수업 요일과 개강 일정은 별도 안내를 확인해 주세요.

Q.

어떤 프로그램과 계정이 필요한가요?

Node.js, VS Code, Claude Code 실습 환경과 Claude·Supabase·Netlify 계정을 준비합니다. 원본 과정의 Claude Pro 기준을 참고하되, 수업에서 사용할 로그인 방식과 필요한 이용권은 개강 전 안내를 확인해 주세요. AI 사용량과 배포 서비스 요금의 수강료 포함 여부도 함께 확인하면 좋습니다.

Q.

무료 플랜으로 계속 운영할 수 있나요?

무료 플랜에도 사용량과 기능 제한이 있으므로 모든 운영 비용이 무료라고 보장하지 않습니다. 수업에서는 적용할 플랜의 제한과 비용 최적화 항목을 확인합니다. 도메인이나 추가 기능, 사용량 증가에 따른 비용은 별도로 점검해야 합니다.

Q.

바로 실제 고객이 사용하는 서비스로 운영해도 되나요?

수업의 배포는 학습용 결과물을 공개하고 동작을 확인하는 실습입니다. 실제 서비스 운영 전에는 데이터 접근 권한, 개인정보, 오류 대응과 사용량을 추가로 검토해야 합니다. 실습 중에는 별도 프로젝트와 예시 데이터를 사용하고 비밀 키를 공개 코드에 넣지 않습니다.
