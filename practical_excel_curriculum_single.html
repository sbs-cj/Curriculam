4개 항목
01엑셀 2021 기초
실무엑셀 · 1일차

엑셀 2021의 화면 구성과 기본 데이터 입력 흐름을 익히고, 워크시트 관리와 편집의 기초를 다집니다.

  • 엑셀 2021의 기초 및 화면 구성요소
  • 기본적인 데이터 입력 및 변환
  • 워크시트 관리, 워크시트 내용 편집 및 찾기와 바꾸기
  • 셀 이동과 복사하기
02문서작성
실무엑셀 · 2일차

보고서와 사무 문서에 필요한 셀 서식, 조건부 서식, 인쇄 설정을 실습하고 함수 주소 체계를 이해합니다.

  • 셀 서식을 이용하여 문서 꾸미기
  • 조건부 서식 사용하기
  • 머리글/바닥글 만들고 워크시트 인쇄하기
  • 상대주소와 절대주소의 차이
  • 기초함수
03문서 작성
실무엑셀 · 3일차

실무에서 자주 쓰는 함수를 적용하고, 데이터 전달력을 높이는 차트와 그래픽 개체, 정렬과 부분합을 다룹니다.

  • 자주 이용하는 실무 함수 사용하기
  • 차트 만들고 편집하기
  • 그래픽 개체 사용하기
  • 데이터 유효성 검사하기
  • 정렬 및 부분합 이용하기
04분석 작업
실무엑셀 · 4일차

자료를 빠르게 추려 보고 요약하는 필터와 피벗 테이블을 익히고, 목표값 찾기와 매크로로 반복 업무를 줄입니다.

  • 자동 필터와 고급 필터
  • 피벗 테이블 사용 및 응용
  • 시나리오와 목표값 찾기
  • 매크로 사용

상담 시에는 “업무에서 엑셀을 써야 하는데 어디서부터 배워야 할지 막막한 분”에게 추천하기 좋습니다. 기본 화면 구성부터 함수, 차트, 피벗 테이블까지 짧은 기간 안에 핵심 기능을 훑고 직접 써보는 흐름입니다.

01 수업 목표
엑셀 기본기 정리

엑셀 2021의 화면 구성, 데이터 입력, 셀 이동과 복사, 워크시트 관리 등 가장 많이 쓰는 기본 조작을 익힙니다.

문서 작성 능력

셀 서식, 조건부 서식, 머리글/바닥글, 인쇄 설정을 활용해 보기 좋은 실무 문서를 작성합니다.

데이터 분석 활용

함수, 정렬, 부분합, 필터, 피벗 테이블, 목표값 찾기와 매크로를 통해 업무 자료를 빠르게 정리합니다.

02 학습 흐름
1단계

기초 조작

엑셀 화면 구성과 데이터 입력, 시트 편집을 익힙니다.

2단계

문서 서식

셀 서식과 조건부 서식, 인쇄 설정으로 보고서를 다듬습니다.

3단계

함수·차트

실무 함수와 차트, 데이터 유효성 검사, 정렬과 부분합을 다룹니다.

4단계

분석 자동화

필터, 피벗 테이블, 목표값 찾기, 매크로로 분석 작업을 마무리합니다.

03 일차별 커리큘럼
실무엑셀 · 1~4일차

Q. 엑셀을 처음 써도 수강할 수 있나요?

네. 선수강 과목이 없는 과정입니다. 화면 구성과 데이터 입력부터 시작해 실무 기능으로 단계적으로 이어갑니다.

Q. 어떤 업무에 도움이 되나요?

일반 사무, 매출·재고 정리, 보고서 작성, 자료 취합, 간단한 데이터 분석처럼 기업 사무직에서 자주 만나는 업무에 도움이 됩니다.

Q. 수업 중 궁금한 기능을 질문할 수 있나요?

가능합니다. 원본 커리큘럼의 수업 방식처럼 알고 싶은 엑셀 기능을 질문하고 피드백받는 형태로 맞춤 설명을 제공합니다.
